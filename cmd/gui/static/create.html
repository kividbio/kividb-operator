Name

Lowercase letters, digits and dashes. The pods are named <name>-0, <name>-1, …

It must exist already.

Build

Which KiviDB build the pods run. Job queues such as BullMQ and Sidekiq run Lua scripts: pick lua or full for them.

standardthe fastest; no Lua, no TLS
luaEVAL, FUNCTION, job queues
tlsTLS listener
fullLua and TLS
Set by the build; change it only to pin another version or registry.
