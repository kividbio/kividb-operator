kividb-operator {{ .Chart.AppVersion }} has been installed into namespace "{{ .Release.Namespace }}".

1. Check that the operator manager is running:

   kubectl -n {{ .Release.Namespace }} get deployment {{ include "kividb-operator.fullname" . }}-manager
   kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "kividb-operator.fullname" . }}-manager -f

{{- if .Values.crds.install }}

2. The KividbCluster / KividbDbOps CRDs were installed with this release.
   Confirm they are present:

   kubectl get crd kividbclusters.kividb.io kividbdbops.kividb.io
{{- else }}

2. crds.install was set to false -- install the CRDs yourself before
   creating any KividbCluster objects:

   kubectl apply -f charts/kividb-operator/crds/
{{- end }}

3. Apply a sample KividbCluster (see config/samples/ in the repository for
   more, including full-featured and MinIO-backed examples):

   kubectl apply -f - <<'EOF'
   apiVersion: kividb.io/v1alpha1
   kind: KividbCluster
   metadata:
     name: my-kividb
     namespace: default
   spec:
     image: quay.io/kividbio/kividb:v1.0.5
     storage:
       size: 5Gi
   EOF

   kubectl get kividbcluster my-kividb
   kubectl get pods -l app.kubernetes.io/instance=my-kividb

{{- if .Values.gui.enabled }}

4. Reach the management GUI via port-forward:

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kividb-operator.gui.fullname" . }} 8090:{{ .Values.gui.service.port }}

   Then open http://localhost:8090 in a browser.
   {{- if .Values.gui.auth.existingSecret }}
   Basic auth is enabled from Secret "{{ .Values.gui.auth.existingSecret }}".
   {{- else }}
   Tip: set gui.auth.existingSecret (keys username/password) to enable Basic
   auth — required for the RESP explorer.
   {{- end }}
   The GUI ServiceAccount never reads Secrets into the browser; it can create
   KividbDbOps restarts and view pod logs.
{{- else }}

4. The web GUI was not installed (gui.enabled=false). Re-install with
   --set gui.enabled=true to add it.
{{- end }}

See https://github.com/kividbio/kividb-operator for docs.
